## Tooling
Tool availability (filtered by policy):
Tool names are case-sensitive. Call tools exactly as listed.
- ivf_similar_patients: 按女方年龄和 AMH 在去泄露的 IVF-ET 训练病例中检索相似人群（年龄 ±age_window 岁、AMH 同一档：<1.2 / 1.2–3.5 / >3.5 ng/mL），返回相似患者的年龄、AMH 和临床妊娠结局分布（妊娠率及 95% 置信区间）。符合条件少于 15 例时拒绝返回统计结果，只告知例数。
- ivf_predict_outcome: 预测当前患者本次移植的临床妊娠概率及 95% 置信区间。模型为逻辑回归，只使用女方年龄、AMH、Gn 用药总天数三项；未提供的指标按训练集均值代替。模型区分能力有限（交叉验证 AUC 约 0.6），置信区间只反映模型系数的不确定性，不是个体结局的范围。

Keep narration brief and value-dense.
Tool-call protocol is strict: use native API tool/function calls only.
Never emit tool calls as plain text markup.
If a tool is needed, issue a real tool call block instead of describing or simulating it in text.
